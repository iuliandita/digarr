Digarr has been deployed!

For defense-in-depth, label the namespace with Pod Security Standards so
future pod specs that weaken the securityContext are rejected at admission:

  kubectl label namespace {{ .Release.Namespace }} \
    pod-security.kubernetes.io/enforce=restricted \
    pod-security.kubernetes.io/enforce-version=latest \
    pod-security.kubernetes.io/audit=restricted \
    pod-security.kubernetes.io/warn=restricted --overwrite

1. Get the application URL:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else if .Values.gateway.enabled }}
  Gateway: {{ .Values.gateway.gatewayName }}
{{- range .Values.gateway.hostnames }}
  Hostname: {{ . }}
{{- end }}
  Check the parent Gateway listener for the public scheme and port.
  Set ingress.controllerNamespace to the Gateway data-plane namespace for NetworkPolicy ingress.
  See the chart README Network access section.
{{- else }}
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "digarr.fullname" . }} 3000:{{ .Values.service.port }}
  echo "Local health endpoint: http://localhost:3000/health"
{{- end }}

Configure ALLOWED_ORIGIN to the exact public origin and set DIGARR_ENCRYPTION_KEY
before saving credentials. Sign in through that public origin; a different
port-forward origin may be rejected. For deliberate local HTTP access through
the port-forward, set ALLOWED_ORIGIN=http://localhost:3000 and
DIGARR_ALLOW_INSECURE_COOKIES=true, then restart the app. Keep insecure cookies
disabled for an HTTPS public origin.

2. Database migrations run automatically on startup.
{{- if not .Values.backups.persistence.enabled }}

  WARNING: backups.persistence.enabled=false. The pre-migration
  JSON auto-backup is partial and lives on an emptyDir lost on pod replacement.
  Set backups.persistence.enabled=true to retain these exports, and keep a
  separate consistent database or data-volume backup for complete recovery.
  See docs/guides/switching-backends.md for backup boundaries.
{{- end }}

3. Check health:
  curl http://<host>/health
{{- if and (eq .Values.database.backend "postgres") .Values.postgresql.enabled }}

Note: Using bundled PostgreSQL ({{ .Values.postgresql.image.repository }}:{{ .Values.postgresql.image.tag }}).
To use your own PostgreSQL (CNPG, RDS, etc.), set postgresql.enabled=false
and configure the database.* values or supply database.existingSecret.
{{- end }}

{{- if and (eq .Values.database.backend "pglite") (not .Values.database.pglite.persistence.enabled) }}

WARNING: PGlite data persistence is disabled. The entire database uses emptyDir
and is deleted when the pod is replaced. Enable database.pglite.persistence.enabled
before storing data you need to retain.
{{- end }}
